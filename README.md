# Roofix Radiance

Create a premium, modern website for **Roofix Coatings**, an Australian roof painting & restoration specialist.

**Info:** Phone: +61 493 741 674 | Email: [roofcoatingss@gmail.com](mailto:roofcoatingss@gmail.com) | Tagline: “Restoring and protecting Aussie roofs.”

Use a **unique cinematic hero**, not a standard layout. Use a subtle **black/dark + green accent** theme with highly readable text.

Create many premium sections: Hero, Services, Roof Transformation, Before & After, Why Choose Us, Process, Work Showcase, Results, Testimonials, Service CTA, Contact and Footer.

Mix image and video sections so the website never feels boring. **Lovable should automatically choose and add high-quality relevant roofing/restoration images and background videos itself.** Use cinematic roof painting, roof cleaning and restoration videos where appropriate.

Make everything smooth, responsive, animated, modern and luxury-looking. Add strong CTAs like **Get a Free Quote** and **Call Now**.
